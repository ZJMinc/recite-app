# 「教基背诵」规划书

> 目标：一个只给自己用的、手机上随时能背的教师招聘《教育基础知识》记忆工具。
> 形态：静态网页 / PWA（手机浏览器可添加到主屏、可离线）。数据存本地，无账号、无后端。

---

## 一、先想清楚一件事

这类 App 的成败 **90% 在内容，10% 在功能**。

刷题软件到处都是，但它们不解决「背不下来」。真正稀缺的是：

1. 知识点被拆成**可独立回忆的最小单元**（一张卡只考一个点）；
2. 每个点都有**遮挡、口诀、易混对比**三种记忆钩子；
3. 系统知道**你今天该背哪 40 张**（间隔重复调度）。

所以本项目的路线是：**先做透 1 个科目、300 张精品卡，验证「真的能背进去」，再扩科目、加功能。**

---

## 二、考试内容范围（知识树）

《教育基础知识》通常覆盖 6 大板块，按分值权重排序：

| 板块 | 主要内容 | 权重参考 |
|---|---|---|
| 教育学 | 教育与教育学、教育与社会/人的发展、教育目的与制度、课程、教学、德育、班级管理、教师与学生、教育研究 | ★★★★★ |
| 教育心理学 | 学生心理发展、学习理论、学习动机、迁移、知识学习、技能形成、问题解决与创造性、学习策略、品德发展、心理健康、教师心理 | ★★★★★ |
| 心理学基础 | 认知过程（感知觉/注意/记忆/思维/想象）、情绪情感、意志、个性心理（需要动机/能力/气质性格）、社会心理 | ★★★★ |
| 教育法律法规 | 教育法、义务教育法、教师法、未成年人保护法、预防未成年人犯罪法、学生伤害事故处理办法、教师资格条例 | ★★★ |
| 教师职业道德 | 中小学教师职业道德规范、新时代教师职业行为十项准则 | ★★★ |
| 新课改 | 课程改革、核心素养、双减、五项管理 | ★★ |

题型覆盖：单选、多选、判断、填空、名词解释、简答、辨析、论述、案例分析。

## 三、记忆方法论 → 产品功能

每个功能都必须对应一个记忆原理，不做花架子。

| 记忆原理 | 落地功能 |
|---|---|
| **主动回忆**（Active Recall） | 先出题干→自己憋答案→再翻面。禁止默认显示答案 |
| **间隔重复**（Spaced Repetition） | FSRS 算法调度，按「忘记/模糊/记住/简单」四档自评，自动算下次复习日 |
| **挖空遮挡**（Cloze） | 关键词挖空，逐字/逐词揭示，适合定义、分类、条目 |
| **首字提示 / 踩点背诵** | 简答题只显示要点首字（如「三爱两人一终身」），逼自己补全 |
| **自上而下框架** | 章→节→知识点骨架先背，再填细节；思维导图式大纲 |
| **精细加工** | 每张卡可挂「口诀」「生活例子」「易混对比」三个附加字段 |
| **易混点辨析** | 对比卡：教育目的 vs 培养目标、顺向迁移 vs 逆向迁移… |
| **测试效应** | 刷题 + 错题重练，做错的题进入强化队列 |
| **输出式记忆** | 简答默写模式：手打答案，系统比对关键词覆盖率给分 |
| **多通道** | TTS 朗读（通勤听背）、暗色模式（睡前背） |

## 四、功能清单（按优先级）

### P0 — MVP，必须最先跑通「背诵闭环」

- **知识树浏览**：科目 → 章 → 节 → 知识点，带掌握度色块
- **卡片学习**：题干 → 自评四档 → 翻面看答案 + 解析 + 口诀
- **挖空背诵模式**：点击/滑动揭示空格
- **今日队列**：新卡 N 张 + 到期复习卡 M 张，一屏一卡，单手操作
- **本地持久化**：IndexedDB，关掉浏览器不丢
- **备份**：一键导出/导入 JSON
- **统计**：连续打卡天数、今日新学/复习数、记忆保持率、各章掌握度
- **PWA**：离线可用、加到手机主屏

### P1 — 让它真正好用

- **题库刷题**：单选/多选/判断，即时判分 + 解析
- **错题本**：自动收录、按错误次数排序、连续答对自动移出
- **简答/论述自评**：要点清单打勾 + 关键词覆盖率
- **学习计划**：填考试日期，倒推每天任务量，落后自动提醒
- **搜索 / 标签 / 收藏 / 标记疑难**
- **日历热力图**：一眼看到哪天摸鱼

### P2 — 加分项

- **模拟考试**：计时、按分值组卷、估分
- **内容编辑器 + 批量导入**（Excel / Markdown / Anki apkg）
- **TTS 听背**
- **AI 辅助**：自动生成干扰项、批改简答、讲解错题（需 API Key）
- **云同步 / 多端**（真要分享给别人时再做）

## 五、技术方案

```
Vite + React + TypeScript + Tailwind CSS
├─ 路由：react-router
├─ 状态：zustand（轻量，够用）
├─ 存储：Dexie.js → IndexedDB（离线优先，无后端）
├─ 算法：ts-fsrs（FSRS-5 调度器，目标记忆率 0.9）
├─ 图表：Recharts（少用）/ 纯 CSS 画热力图
├─ PWA：vite-plugin-pwa
└─ 内容：内置 JSON（打包进产物）+ 后续支持导入
```

选型理由：

- **纯静态**：任何静态托管都能放（Vercel / Cloudflare Pages / 甚至本地 `npx serve`），零月费、零运维；
- **IndexedDB**：几百 MB 卡片数据无压力，离线完全可用；
- **FSRS 而非 SM-2**：同等复习量下记忆保持率更高，且有成熟的 `ts-fsrs` 库，不用自己推公式；
- **不选小程序**：富文本/公式/离线能力弱，还要备案；PWA 现在能覆盖 95% 需求。

## 六、数据模型

```ts
Subject        { id, name, order }
Chapter        { id, subjectId, parentId, title, order }        // 自关联成树
KnowledgePoint { id, chapterId, title, summary,                   // 一个考点
                 mnemonics: string[],                             // 口诀
                 confusables: string[],                           // 易混点
                 importance: 1..5 }
Card           { id, kpId, type:                        // cloze|qa|choice|judge|short
                 front, back, clozeText?, blanks?,
                 options?, answer?, analysis?,
                 tags: string[] }
ReviewState    { cardId, stability, difficulty, due, reps, lapses, state }  // FSRS
ReviewLog      { id, cardId, rating(1-4), reviewedAt, elapsedMs }
WrongItem      { cardId, wrongCount, lastWrongAt, resolved }
Settings       { dailyNewLimit, dailyReviewLimit, targetRetention, examDate }
DailyStat      { date, newCount, reviewCount, correctRate, minutes }
```

关键设计：**知识点（KnowledgePoint）是内容单位，卡片（Card）是记忆单位**。
一个知识点可以派生多张卡（定义卡、分类卡、对比卡、挖空卡），这样「背一个考点」可以从多个角度反复锤。

## 七、实施里程碑

| 阶段 | 交付物 | 预估 |
|---|---|---|
| **M0 内容骨架** | 6 大板块章节树 + 教育学/教育心理学各 1 章精编示例卡（约 80 张） | 1 天 |
| **M1 背诵闭环** | 知识树 + 卡片复习 + FSRS 调度 + 今日队列 + 统计 + 本地存储 | 2–3 天 |
| **M2 刷题** | 选择题/判断题刷题 + 错题本 | 1–2 天 |
| **M3 输出式记忆** | 简答自评 + 默写 + 学习计划 + 热力图 | 1–2 天 |
| **M4 打磨** | PWA 离线、备份导入导出、暗色模式、手机适配 | 1 天 |
| **M5 扩内容** | 按板块批量补卡，目标 1500–3000 张 | 持续 |

**M1 结束就能每天真实使用**，后面都是增量。

## 八、需要提前避开的坑

1. **别一上来做账号系统**——单机本地存储足够，省掉 80% 复杂度；
2. **别做「浏览模式」当主入口**——只读不考等于没背，复习队列才是首页；
3. **手机优先**：大按钮、拇指热区、单手可完成「翻面 + 评分」；
4. **内容分单元要足够小**：一张卡超过 3 个要点就拆开；
5. **真题版权**：自己整理改写，不要直接抓题库站的内容商用；
6. **备份要显眼**：IndexedDB 可能被浏览器清理，导出按钮放设置首页。

## 九、下一步

建议直接开工 **M0 + M1**，先拿到一个「能真正背起来」的可运行原型，用 3 天真实使用后再决定功能取舍。
